# 4.5 Instance Binding

## Overview

**Instance Binding** means binding an **already-created object instance** to Laravel's Service Container.

Unlike `bind()`, Laravel does not create the object. You create it first and give that exact instance to the container.

## Basic Example

```php
$paymentService = new PaymentService();

$this->app->instance(
    PaymentService::class,
    $paymentService
);
```

Now whenever Laravel resolves `PaymentService`, it returns the same `$paymentService` object.

```php
$service = app(PaymentService::class);
```

## `instance()` vs `singleton()`

### Instance Binding

```php
$service = new PaymentService();

$this->app->instance(
    PaymentService::class,
    $service
);
```

You **create the object yourself** and Laravel stores it.

### Singleton Binding

```php
$this->app->singleton(
    PaymentService::class,
    PaymentService::class
);
```

Laravel **creates the object when it is first resolved** and then reuses it.

| Instance Binding | Singleton Binding |
|---|---|
| You create the object | Container creates the object |
| Existing object is registered | Class/factory is registered |
| Uses `instance()` | Uses `singleton()` |

## Practical Example

Suppose an application already has a configured API client:

```php
$client = new ApiClient(
    config('services.payment.key')
);

$this->app->instance(ApiClient::class, $client);
```

Now Laravel can inject this exact client wherever needed:

```php
class PaymentService
{
    public function __construct(
        private ApiClient $client
    ) {}
}
```

## When to Use Instance Binding

Useful when:

- You already have an object.
- The object requires custom setup before registration.
- You need Laravel to use that exact object.
- Testing requires a specific object or mock.

## Interview Questions

**Q: What is instance binding?**  
It registers an already-created object instance in the Service Container.

**Q: Which method is used for instance binding?**

```php
$this->app->instance(ClassName::class, $object);
```

**Q: Does Laravel create the object in instance binding?**  
No. The object is created before calling `instance()`.

**Q: Instance binding vs singleton?**  
With instance binding, you provide the object yourself. With singleton binding, Laravel creates and stores the object when it is first resolved.
