# 4.10 Extending Bindings

## Overview

**Extending Bindings** allows you to modify or decorate an existing service when Laravel resolves it.
It is useful when you want to **add behavior to an existing service without changing its original class**.

## Basic Example

Suppose Laravel already has a `ReportService`:

```php
$this->app->bind(ReportService::class);
```

You can extend it:

```php
$this->app->extend(ReportService::class, function ($service, $app) {
    $service->enableLogging();

    return $service;
});
```

Laravel first creates the original service, then passes it to the closure so you can modify or wrap it.

## Wrapping a Service

You can also return another object that uses the original service:

```php
$this->app->extend(ReportService::class, function ($service, $app) {
    return new LoggingReportService($service);
});
```

```text
ReportService
     ↓
Container resolves it
     ↓
extend()
     ↓
Add / modify behavior
     ↓
Final service
```

## Why Use Extending Bindings?

Useful when you want to:

- Add logging.
- Add caching.
- Add monitoring.
- Modify an existing service.
- Decorate a service without changing its original code.

## `extend()` Syntax

```php
$this->app->extend(
    Service::class,
    function ($service, $app) {
        // Modify or wrap service

        return $service;
    }
);
```

The closure must return the service that should be used by the container.

## Where to Use It

Usually inside a Service Provider:

```php
public function register()
{
    $this->app->extend(ReportService::class, function ($service, $app) {
        return new LoggingReportService($service);
    });
}
```

## Binding vs Extending

```text
bind()
  ↓
Defines how a service is created

extend()
  ↓
Modifies / decorates an existing service
```

## Interview Questions

**Q: What is `extend()` in Laravel?**  
It allows you to modify or decorate an existing service registered in the Service Container.

**Q: Which method is used?**

```php
$this->app->extend(...)
```

**Q: Why use `extend()` instead of modifying the original class?**  
To add behavior without changing the original implementation.

**Q: What must the `extend()` callback return?**  
The service instance that should be used by the container.
