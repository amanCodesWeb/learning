# 4.2 Automatic Resolution

## Overview

Laravel's **Service Container** can automatically create concrete classes and inject their dependencies without manually registering them.

```php
class PaymentService
{
    public function process()
    {
        return "Payment successful";
    }
}

class OrderController
{
    public function __construct(
        private PaymentService $payment
    ) {}
}
```

Laravel sees `PaymentService`, creates it, and injects it into `OrderController`.

## How It Works

```text
OrderController
    ↓
PaymentService required
    ↓
Service Container
    ↓
Creates PaymentService
    ↓
Injects it
```

Laravel uses PHP's **Reflection API** to inspect constructor dependencies.

## Nested Dependencies

Laravel can resolve dependencies recursively.

```php
class PaymentService
{
    public function __construct(
        private PaymentGateway $gateway
    ) {}
}

class OrderController
{
    public function __construct(
        private PaymentService $payment
    ) {}
}
```

```text
OrderController
    ↓
PaymentService
    ↓
PaymentGateway
```

## Manual Resolution

You can also resolve a class from the container manually:

```php
$service = app(PaymentService::class);

$service = resolve(PaymentService::class);
```

## When Automatic Resolution Works

It works when:

- The class is concrete.
- The class can be instantiated.
- Dependencies are type-hinted classes.

It does **not** automatically know how to resolve:

- Interfaces
- Primitive values like `string`, `int`
- Runtime values

For interfaces, define a binding:

```php
$this->app->bind(
    PaymentGatewayInterface::class,
    StripePaymentGateway::class
);
```

## Automatic Resolution vs DI

**Dependency Injection:** Passing dependencies into a class.

**Automatic Resolution:** Laravel automatically creates those dependencies using the Service Container.

## Interview Questions

**Q: What is automatic resolution?**  
Laravel automatically creates concrete classes and their dependencies through the Service Container.

**Q: How does Laravel know what dependencies a class needs?**  
It uses PHP's Reflection API to inspect the constructor.

**Q: Can Laravel automatically resolve interfaces?**  
No. An interface normally requires a container binding.

**Q: Can Laravel resolve nested dependencies?**  
Yes. It recursively resolves type-hinted dependencies.

**Q: How can you manually resolve a class?**

```php
app(MyService::class);
resolve(MyService::class);
```

```text
    ↓

```

**Key Point:** Automatic Resolution reduces the need for manually registering simple concrete classes.
