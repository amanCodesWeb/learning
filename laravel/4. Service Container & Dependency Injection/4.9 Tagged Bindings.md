# 4.9 Tagged Bindings

## Overview

**Tagged Bindings** allow you to group multiple services under the same **tag** and resolve them together.
This is useful when you have multiple implementations of the same type of service.

## Basic Example

```php
$this->app->bind(StripeGateway::class);
$this->app->bind(PayPalGateway::class);

$this->app->tag(
    [StripeGateway::class, PayPalGateway::class],
    'payment-gateways'
);
```
Now both services belong to the `payment-gateways` tag.

## Resolving Tagged Services

```php
$gateways = $this->app->tagged('payment-gateways');
```
Laravel returns the tagged services as an array.

```text
payment-gateways
       ↓
 ┌──────────────┐
 │ Stripe       │
 │ PayPal       │
 └──────────────┘
```

## Practical Example

Suppose your application supports multiple notification services:

```php
$this->app->bind(EmailNotification::class);
$this->app->bind(SmsNotification::class);
$this->app->bind(PushNotification::class);

$this->app->tag(
    [
        EmailNotification::class,
        SmsNotification::class,
        PushNotification::class
    ],
    'notifications'
);
```

Resolve them:

```php
$notifications = app()->tagged('notifications');
```

You can then loop through all notification services:

```php
foreach ($notifications as $notification) {
    $notification->send();
}
```

## Why Use Tagged Bindings?

Useful when:

- Multiple services perform a similar role.
- You need to process all implementations together.
- You want a clean way to group related services.
- New implementations may be added later.

## `tag()` vs `tagged()`

```php
// Assign services to a tag
$this->app->tag(
    [ServiceA::class, ServiceB::class],
    'services'
);

// Get all services with that tag
$this->app->tagged('services');
```

## Interview Questions

**Q: What are tagged bindings?**  
They allow multiple services to be grouped under one tag and resolved together.

**Q: Which methods are used?**

```php
tag()
tagged()
```

**Q: When would you use tagged bindings?**  
When an application has multiple implementations or services that need to be processed as a group.

**Q: Does a tag create a new binding?**  
No. It groups existing container bindings under a common tag.
