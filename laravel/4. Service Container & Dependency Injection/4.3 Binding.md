# 4.3 Binding

## Overview

**Binding** tells Laravel's Service Container **which implementation to use when a dependency is requested**.

It is mainly useful for **interfaces, custom implementations, or controlling object creation**.

## Basic Binding

```php
$this->app->bind(
    PaymentGatewayInterface::class,
    StripePaymentGateway::class
);
```

Now whenever Laravel needs `PaymentGatewayInterface`, it creates `StripePaymentGateway`.

```php
class OrderController
{
    public function __construct(
        private PaymentGatewayInterface $gateway
    ) {}
}
```

## Where to Bind

Usually bindings are defined in a **Service Provider**:

```php
public function register()
{
    $this->app->bind(
        PaymentGatewayInterface::class,
        StripePaymentGateway::class
    );
}
```

## `bind()` vs `singleton()`

### `bind()`

Creates a new instance when resolved.

```php
$this->app->bind(
    PaymentService::class,
    PaymentService::class
);
```

### `singleton()`

Creates one instance and reuses it.

```php
$this->app->singleton(
    PaymentService::class,
    PaymentService::class
);
```

```text
bind()       → New instance
singleton()  → Same instance
```

## Binding With Closure

You can control how an object is created:

```php
$this->app->bind(PaymentService::class, function () {
    return new PaymentService();
});
```

## Why Use Binding?

- Connect interfaces to implementations.
- Replace implementations easily.
- Control object creation.
- Make code easier to test.
- Reduce tight coupling.

## Practical Example

```php
interface PaymentGateway
{
    public function pay();
}

class StripeGateway implements PaymentGateway
{
    public function pay()
    {
        return "Paid with Stripe";
    }
}
```

Bind it:

```php
$this->app->bind(
    PaymentGateway::class,
    StripeGateway::class
);
```

Now Laravel can inject `PaymentGateway` anywhere.

## Interview Questions

**Q: What is binding in Laravel?**  
Binding tells the Service Container how to resolve a dependency.

**Q: Why is binding commonly used with interfaces?**  
Because Laravel cannot know which concrete implementation an interface should use.

**Q: `bind()` vs `singleton()`?**  
`bind()` can create a new instance on each resolution, while `singleton()` reuses the same instance.

**Q: Where are bindings usually defined?**  
Inside a Service Provider's `register()` method.
