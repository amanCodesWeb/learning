# 4.7 Contextual Binding

## Overview

**Contextual Binding** allows Laravel to use **different implementations of the same interface depending on which class needs it**.

Normal binding:

```php
$this->app->bind(
    PaymentGateway::class,
    StripeGateway::class
);
```

This means every class requesting `PaymentGateway` gets `StripeGateway`.
With contextual binding, different classes can get different implementations.

## Basic Example

```php
interface PaymentGateway
{
    public function pay();
}

class StripeGateway implements PaymentGateway
{
    public function pay()
    {
        return "Stripe";
    }
}

class PayPalGateway implements PaymentGateway
{
    public function pay()
    {
        return "PayPal";
    }
}
```

Suppose `OrderService` needs Stripe:

```php
class OrderService
{
    public function __construct(
        private PaymentGateway $gateway
    ) {}
}
```

But `SubscriptionService` needs PayPal:

```php
class SubscriptionService
{
    public function __construct(
        private PaymentGateway $gateway
    ) {}
}
```

Define contextual bindings:

```php
$this->app->when(OrderService::class)
    ->needs(PaymentGateway::class)
    ->give(StripeGateway::class);

$this->app->when(SubscriptionService::class)
    ->needs(PaymentGateway::class)
    ->give(PayPalGateway::class);
```

Now:

```text
OrderService
    ↓
PaymentGateway → StripeGateway

SubscriptionService
    ↓
PaymentGateway → PayPalGateway
```

## Why Use Contextual Binding?

Use it when **the same dependency needs different implementations in different classes**.

Examples:

- Different payment gateways
- Different notification services
- Different storage implementations
- Different API clients

## Normal Binding vs Contextual Binding

```text
Normal Binding
PaymentGateway → StripeGateway

Contextual Binding
OrderService       → StripeGateway
SubscriptionService → PayPalGateway
```

## Where to Define It

Usually inside a Service Provider's `register()` method:

```php
public function register()
{
    $this->app->when(OrderService::class)
        ->needs(PaymentGateway::class)
        ->give(StripeGateway::class);
}
```

## Interview Questions

**Q: What is contextual binding?**  
It allows Laravel to provide different implementations of the same dependency depending on the class requesting it.

**Q: Why use contextual binding?**  
When different classes need different implementations of the same interface.

**Q: Which methods are used?**

```php
when()
needs()
give()
```

**Q: Normal binding vs contextual binding?**  
Normal binding defines one general implementation, while contextual binding defines an implementation for a specific class.

## Quick Revision

```text
Same Interface
      ↓
Different Classes
      ↓
Contextual Binding
      ↓
Different Implementations
```

**Key Point:** Contextual Binding means **"give this implementation when this specific class needs this dependency."**
