# 2.2 Resource Controllers

## Overview

A **Resource Controller** is a controller designed to handle standard CRUD operations for a resource.

CRUD means:

- Create
- Read
- Update
- Delete

Laravel can automatically generate the standard CRUD methods using:

```bash
php artisan make:controller UserController --resource
```

## Creating a Resource Controller
```bash
php artisan make:controller UserController --resource
```
## Laravel creates:
app/Http/Controllers/UserController.php

The controller contains seven standard methods:

```php
class UserController extends Controller
{
    public function index(){}
    public function create(){}
    public function store(Request $request){}
    public function show(string $id){}
    public function edit(string $id){}
    public function update(Request $request, string $id){}
    public function destroy(string $id){}
}
```

## Resource Routes

Instead of defining every CRUD route manually:

```php
Route::get('/users', [UserController::class, 'index']);
Route::get('/users/create', [UserController::class, 'create']);
Route::post('/users', [UserController::class, 'store']);
Route::get('/users/{user}', [UserController::class, 'show']);
Route::get('/users/{user}/edit', [UserController::class, 'edit']);
Route::put('/users/{user}', [UserController::class, 'update']);
Route::delete('/users/{user}', [UserController::class, 'destroy']);
```

USE:

```php
Route::resource('users', UserController::class);
```
Laravel automatically creates the standard CRUD routes.


## Resource Controller Methods

| Method      | HTTP Verb | URI                  | Purpose          |
| ----------- | --------- | -------------------- | ---------------- |
| `index()`   | GET       | `/users`             | Display users    |
| `create()`  | GET       | `/users/create`      | Show create form |
| `store()`   | POST      | `/users`             | Store new user   |
| `show()`    | GET       | `/users/{user}`      | Display one user |
| `edit()`    | GET       | `/users/{user}/edit` | Show edit form   |
| `update()`  | PUT/PATCH | `/users/{user}`      | Update user      |
| `destroy()` | DELETE    | `/users/{user}`      | Delete user      |


## Route Model Binding
Resource routes commonly work with Implicit Route Model Binding.

Route:
```php
Route::resource('users', UserController::class);
```

Controller:
```php
public function show(User $user)
{
    return $user;
}
```
Request:
```
/users/10
```

Laravel automatically finds the User model with ID 10 and injects it into $user.

Without Route Model Binding:
```php
public function show($id)
{
    $user = User::findOrFail($id);

    return $user;
}
```

With Route Model Binding:
```php
public function show(User $user)
{
    return $user;
}
```

## Resource Route Names
Resource routes automatically receive names:

users.index
users.create
users.store
users.show
users.edit
users.update
users.destroy

## Example:
```php
return redirect()->route('users.index');
```

## Limiting Resource Routes

If you only need specific actions:

```php
Route::resource('users', UserController::class)
    ->only(['index', 'show']);
```

This creates only:
GET /users
GET /users/{user}

You can also exclude specific actions:

```php
Route::resource('users', UserController::class)
    ->except(['destroy']);
```

## API Resource Routes

For APIs, use:
```php
php artisan make:controller UserController --api
```

This creates a controller without:
create()
edit()

Because APIs normally return JSON instead of HTML forms.

Route:
```php
Route::apiResource('users', UserController::class);
```

API resource routes:
GET     /users
POST    /users
GET     /users/{user}
PUT     /users/{user}
PATCH   /users/{user}
DELETE  /users/{user}


## Resource Controller vs Basic Controller

### Basic Controller
You manually define the methods:

```php
class UserController extends Controller
{
    public function login()
    {
        //
    }

    public function profile()
    {
        //
    }
}
```

### Resource Controller

Laravel provides the standard CRUD methods:

```php
class UserController extends Controller
{
    public function index() {}
    public function create() {}
    public function store() {}
    public function show() {}
    public function edit() {}
    public function update() {}
    public function destroy() {}
}
```

Use a Resource Controller when a controller mainly handles CRUD operations for a resource.

## Useful Commands

Create Resource Controller
```php
php artisan make:controller UserController --resource
```

Create API Controller
```php
php artisan make:controller UserController --api
```

Create Resource Controller with Model
```php
php artisan make:controller UserController --resource --model=User
```

View Registered Routes
```php
php artisan route:list
```


## Interview Questions
1. What is a Resource Controller?
A controller that provides standard methods for handling CRUD operations on a resource.

2. How do you create a Resource Controller?
php artisan make:controller UserController --resource

3. How do you create Resource Routes?
Route::resource('users', UserController::class);

4. How many methods does a Resource Controller have?
A standard Resource Controller has seven methods:
index
create
store
show
edit
update
destroy

5. What is the difference between resource() and apiResource()?
resource() creates seven routes, including create and edit.
apiResource() creates API CRUD routes and excludes create and edit.

6. Can Resource Routes be limited?
Yes.
Route::resource('users', UserController::class)
    ->only(['index', 'show']);

7. What is Route Model Binding?
It allows Laravel to automatically resolve a route parameter into a model instance.

public function show(User $user)
{
    return $user;
}

8. What are Resource Route Names?
Laravel automatically creates names such as:
users.index
users.create
users.store
users.show
users.edit
users.update
users.destroy

## Key Takeaways
- Resource Controllers are used for standard CRUD operations.
- Create them using --resource.
- Route::resource() automatically creates seven CRUD routes.
- Resource Controllers contain seven standard methods.
- apiResource() is used for API CRUD routes.
- only() and except() can limit resource routes.
- Resource routes work well with Route Model Binding.
- Resource routes automatically generate route names.
