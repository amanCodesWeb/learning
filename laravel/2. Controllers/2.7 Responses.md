# 2.7 Responses

## Overview

A **Response** is the data Laravel sends back to the client after processing a request.

A response can contain:

* HTML
* JSON
* Redirects
* Files
* Downloads
* Status codes
* Headers

Basic example:

```php
public function index()
{
    return "Hello Laravel";
}
```

---

## View Response

Return a Blade view:

```php
public function index()
{
    return view('users.index');
}
```

Pass data to the view:

```php
public function show()
{
    $user = User::find(1);

    return view('users.show', [
        'user' => $user,
    ]);
}
```

---

## JSON Response

For APIs, return JSON:

```php
public function show($id)
{
    $user = User::find($id);

    return response()->json([
        'user' => $user,
    ]);
}
```

Example response:

```json
{
    "user": {
        "id": 1,
        "name": "Aman"
    }
}
```

---

## JSON with Status Code

You can specify an HTTP status code:

```php
return response()->json([
    'message' => 'User created successfully'
], 201);
```

Common status codes:

```text
200 OK
201 Created
204 No Content
400 Bad Request
401 Unauthorized
403 Forbidden
404 Not Found
422 Unprocessable Content
500 Server Error
```

---

## Redirect Response

Redirect the user to another route:

```php
return redirect('/users');
```

Redirect to a named route:

```php
return redirect()->route('users.index');
```

Redirect with a message:

```php
return redirect()
    ->route('users.index')
    ->with('success', 'User created successfully.');
```

In Blade:

```php
{{ session('success') }}
```

---

## Redirect Back

Return the user to the previous page:

```php
return redirect()->back();
```

This is commonly used after form submissions.

---

## Response Headers

You can add custom headers:

```php
return response()
    ->json(['message' => 'Success'])
    ->header('X-App-Version', '1.0');
```

Multiple headers:

```php
return response()
    ->json(['message' => 'Success'])
    ->withHeaders([
        'X-App-Version' => '1.0',
        'X-Custom-Header' => 'value',
    ]);
```

---

## Response Status

You can create a response with a specific status:

```php
return response('Not Found', 404);
```

Or:

```php
return response()
    ->json(['message' => 'Not Found'], 404);
```

---

## File Response

Return a file to the browser:

```php
return response()->file(
    storage_path('app/public/document.pdf')
);
```

This displays the file in the browser when supported.

---

## Download Response

Force the browser to download a file:

```php
return response()->download(
    storage_path('app/public/report.pdf')
);
```

You can specify the download filename:

```php
return response()->download(
    storage_path('app/public/report.pdf'),
    'monthly-report.pdf'
);
```

---

## Resource Responses

Laravel API Resources can transform models into API-friendly responses.

```php
return new UserResource($user);
```

For multiple users:

```php
return UserResource::collection($users);
```

API Resources are useful when you want consistent control over the JSON structure returned by your API.

---

## Response Macros

Laravel allows reusable response methods using **Response Macros**.

For example, you could define a common API response format:

```php
return response()->success(
    $data,
    'User created successfully'
);
```

This is useful when an application has a consistent API response structure.

---

## API Response Example

A typical controller method:

```php
public function store(StoreUserRequest $request)
{
    $user = User::create(
        $request->validated()
    );

    return response()->json([
        'message' => 'User created successfully',
        'data' => $user,
    ], 201);
}
```

Response:

```json
{
    "message": "User created successfully",
    "data": {
        "id": 1,
        "name": "Aman"
    }
}
```

---

## Choosing the Response Type

```text
Web Page
   ↓
return view(...)

API
   ↓
return response()->json(...)

Redirect
   ↓
return redirect(...)

Display File
   ↓
return response()->file(...)

Download File
   ↓
return response()->download(...)
```

## Interview Point

**Q: What types of responses can Laravel return?**

**Answer:**
Laravel can return views, JSON responses, redirects, files, downloads, and custom HTTP responses with status codes and headers.

**Q: How do you return a JSON response?**

```php
return response()->json([
    'message' => 'Success'
], 200);
```

**Q: How do you redirect to a named route?**

```php
return redirect()->route('users.index');
```

**Remember:**

```text
Request
   ↓
Controller
   ↓
Response
   ↓
Client
```
