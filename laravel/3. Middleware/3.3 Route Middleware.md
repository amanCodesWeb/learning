# 3.3 Route Middleware

## Overview

**Route Middleware** runs only on specific routes or route groups.

```text
Request
   ↓
Route Middleware
   ↓
Controller
   ↓
Response
```

## Creating Middleware

```bash
php artisan make:middleware CheckAdmin
```

Example:

```php
class CheckAdmin
{
    public function handle(Request $request, Closure $next): Response
    {
        if (!auth()->user()?->is_admin) {
            abort(403);
        }

        return $next($request);
    }
}
```

## Registering Middleware

In current Laravel versions, define the middleware alias in:

```text
bootstrap/app.php
```

```php
use App\Http\Middleware\CheckAdmin;

->withMiddleware(function (Middleware $middleware) {
    $middleware->alias([
        'admin' => CheckAdmin::class,
    ]);
})
```

## Applying to a Route

```php
Route::get('/admin/dashboard', function () {
    return view('admin.dashboard');
})->middleware('admin');
```

Only this route uses the `admin` middleware.

## Route Groups

Apply middleware to multiple routes:

```php
Route::middleware('admin')->group(function () {
    Route::get('/admin', ...);
    Route::get('/admin/users', ...);
    Route::get('/admin/orders', ...);
});
```

## Multiple Middleware

```php
Route::middleware(['auth', 'admin'])->group(function () {
    Route::get('/admin/dashboard', ...);
});
```

Middleware runs in the defined order.

## Global vs Route Middleware

| Global Middleware      | Route Middleware         |
| ---------------------- | ------------------------ |
| Runs on every request  | Runs on selected routes  |
| Registered globally    | Applied to routes/groups |
| Logging, CORS, headers | Auth, admin, permissions |

## Common Uses

* Authentication
* Admin authorization
* Role/permission checks
* Subscription checks
* Route-specific request rules

## Interview Point

**Q: What is Route Middleware?**
Middleware that is applied only to specific routes or route groups.

**Q: Can multiple middleware be used on one route?**

Yes:

```php
->middleware(['auth', 'admin'])
```

**Remember:**

```text
Global Middleware
      ↓
Route Middleware
      ↓
Controller
      ↓
Response
```
