# 3.4 Middleware Parameters

## Overview

**Middleware Parameters** allow us to pass extra values to middleware when applying it to a route.

Useful for:

* Roles
* Permissions
* Access levels
* Subscription types

## Defining Parameters

```php
public function handle(
    Request $request,
    Closure $next,
    string $role
): Response {
    if (auth()->user()?->role !== $role) {
        abort(403);
    }

    return $next($request);
}
```

## Passing Parameters

```php
Route::get('/admin', ...)
    ->middleware('role:admin');
```

Multiple parameters:

```php
->middleware('role:admin,manager');
```

The values after `:` are passed to the middleware.

```text
role:admin
     ↓
$role = "admin"
```

## Example

Middleware:

```php
public function handle(
    Request $request,
    Closure $next,
    string $role
): Response {
    if (auth()->user()?->role !== $role) {
        abort(403);
    }

    return $next($request);
}
```

Route:

```php
Route::get('/admin', ...)
    ->middleware('role:admin');
```

Only users with the `admin` role can access the route.

## Multiple Parameters

```php
public function handle(
    Request $request,
    Closure $next,
    string $role,
    string $level
): Response {
    // ...
}
```

```php
->middleware('role:admin,super');
```

Values are received in the same order:

```text
admin → $role
super → $level
```

## Interview Point

**Q: Why use middleware parameters?**
To make middleware reusable with different values instead of creating separate middleware for each case.

**Remember:**

```text
Route
  ↓
middleware('role:admin')
  ↓
$role = 'admin'
  ↓
Middleware Logic
  ↓
Controller
```
