# 0.1 What is Laravel?

## Overview

Laravel is a **free, open-source PHP web application framework** designed to build modern, secure, scalable, and maintainable web applications. It provides a structured development environment with built-in tools that simplify common tasks such as routing, authentication, database management, validation, caching, sessions, file handling, and more.

Laravel follows the **MVC (Model-View-Controller)** architectural pattern, which separates an application into three main layers:

- **Model** → Handles data and business logic.
- **View** → Displays data to the user.
- **Controller** → Processes requests and connects the Model with the View.

This separation makes applications easier to develop, maintain, test, and scale.

Laravel was created by **Taylor Otwell** and was first released in **June 2011**. It has become one of the most popular PHP frameworks due to its elegant syntax, powerful features, and rich ecosystem.

---

# What is a Framework?

A framework is a collection of pre-written code, libraries, tools, and conventions that provides a foundation for building applications.

Instead of writing common functionality from scratch, developers use a framework to:

- Reduce development time.
- Avoid code duplication.
- Follow best practices.
- Build organized and maintainable applications.

Think of a framework as the **foundation of a building**. Instead of creating everything from scratch, you build your application on top of an already prepared structure.

# Simple Example

### Plain PHP

```php
<?php

$conn = new mysqli("localhost", "root", "", "shop");

$result = $conn->query("SELECT * FROM users");

while ($row = $result->fetch_assoc()) {
    echo $row['name'];
}
```

### Laravel (Eloquent ORM)

```php
$users = User::all();

foreach ($users as $user) {
    echo $user->name;
}
```

Laravel abstracts low-level database operations, making the code cleaner, more readable, and easier to maintain.

# Best Practices

- Follow Laravel's conventions instead of creating your own project structure.
- Use built-in Laravel features whenever possible.
- Write clean, readable, and maintainable code.
- Keep business logic separate from controllers.
- Leverage Eloquent ORM instead of excessive raw SQL.
- Stay up to date with the latest Laravel releases and best practices.

---

# Common Mistakes

- Treating Laravel as just another PHP library.
- Writing all business logic inside controllers.
- Ignoring Laravel's built-in features and reinventing them.
- Using raw SQL unnecessarily when Eloquent or Query Builder is more appropriate.
- Not following Laravel's recommended project structure.

# Interview Questions

### 1. What is Laravel?

**Answer:**

Laravel is a free, open-source PHP web application framework that follows the MVC architecture. It provides built-in features such as routing, authentication, Eloquent ORM, middleware, validation, caching, queues, and security, enabling developers to build modern web applications efficiently.

---

### 2. Who created Laravel?

**Answer:**

Laravel was created by **Taylor Otwell** and first released in **June 2011**.

---

### 3. Is Laravel a programming language?

**Answer:**

No. Laravel is a PHP framework.

PHP is the programming language, while Laravel provides the structure, tools, and libraries required to build applications efficiently.

---

### 4. Is Laravel a CMS?

**Answer:**

No. Laravel is a web application framework.

A CMS (Content Management System) is an application used to manage content. Laravel can be used to build a CMS, but it is not one itself.

---

Laravel is popular because it provides:

These features significantly reduce development time and improve code quality.
