# 0.8 Artisan CLI

## Overview

**Artisan** is Laravel's built-in **Command Line Interface (CLI)**. It provides commands to create files, manage the application, run database migrations, clear caches, execute queues, and automate repetitive development tasks.

The Artisan executable is located in the project's root directory:

```bash
php artisan
```

---

# Why Use Artisan?

- Automates repetitive tasks.
- Generates boilerplate code.
- Manages database migrations.
- Clears and caches application data.
- Runs queues and scheduled tasks.
- Improves developer productivity.

---

# Common Artisan Commands

### Create Files

Create Controller:

```bash
php artisan make:controller UserController
```

Create Model:

```bash
php artisan make:model User
```

Create Model with Migration:

```bash
php artisan make:model Product -m
```

Create Migration:

```bash
php artisan make:migration create_products_table
```

Create Seeder:

```bash
php artisan make:seeder ProductSeeder
```

Create Middleware:

```bash
php artisan make:middleware CheckAdmin
```

---

### Database Commands

Run Migrations:

```bash
php artisan migrate
```

Rollback Last Migration:

```bash
php artisan migrate:rollback
```

Refresh Database:

```bash
php artisan migrate:refresh
```

Seed Database:

```bash
php artisan db:seed
```

---

### Cache Commands

Clear Application Cache:

```bash
php artisan cache:clear
```

Clear Config Cache:

```bash
php artisan config:clear
```

Cache Configuration:

```bash
php artisan config:cache
```

Clear Route Cache:

```bash
php artisan route:clear
```

Cache Routes:

```bash
php artisan route:cache
```

Clear View Cache:

```bash
php artisan view:clear
```

Optimize Application:

```bash
php artisan optimize
```

---

### Development Commands

Start Development Server:

```bash
php artisan serve
```

List All Routes:

```bash
php artisan route:list
```

Open Interactive Shell:

```bash
php artisan tinker
```

List All Artisan Commands:

```bash
php artisan list
```

Get Help for a Command:

```bash
php artisan help migrate
```

---

# Custom Artisan Commands

You can create your own Artisan commands.

```bash
php artisan make:command SendEmails
```

The command is created in:

```
app/Console/Commands/
```

---

# Best Practices

- Use Artisan generators instead of creating files manually.
- Cache configuration and routes in production.
- Avoid using `route:cache` if your routes contain Closures.
- Use `route:list` to debug routing issues.
- Use `tinker` for quick testing.

---

# Common Mistakes

- Editing generated files without understanding their purpose.
- Running `composer dump-autoload` when an Artisan command would suffice.
- Using `route:cache` with Closure routes.
- Forgetting to clear caches after configuration changes.

# Interview Questions

### 1. What is Artisan?

**Answer:**  
Artisan is Laravel's built-in command-line interface used to generate code, manage the application, run migrations, clear caches, and automate development tasks.

---

### 2. How do you list all available Artisan commands?

**Answer:**

```bash
php artisan list
```

---

### 3. Which command starts Laravel's development server?

**Answer:**

```bash
php artisan serve
```

---

### 4. How do you display all registered routes?

**Answer:**

```bash
php artisan route:list
```

---

### 5. What is Laravel Tinker?

**Answer:**  
Tinker is an interactive REPL (Read-Eval-Print Loop) that allows you to execute PHP and Laravel code directly from the command line.

```bash
php artisan tinker
```

# Key Takeaways

- Artisan is Laravel's CLI tool.
- It automates common development tasks.
- Use `make:*` commands to generate files.
- Use migration commands to manage the database.
- Use cache commands for application optimization.
- `route:list` and `tinker` are essential debugging tools.
- You can create custom Artisan commands for project-specific tasks.
