# 0.7 Configuration Files

## Overview

Laravel stores application configuration in the **`config/`** directory. Each file manages a specific part of the application, such as the database, mail, cache, filesystem, or queue.

Configuration values are typically loaded from the `.env` file, making it easy to change settings for different environments.

---

# Configuration Directory

```text
config/
├── app.php
├── auth.php
├── cache.php
├── database.php
├── filesystems.php
├── logging.php
├── mail.php
├── queue.php
├── services.php
├── session.php
...
```

---

# Common Configuration Files

| File | Purpose |
|------|---------|
| `app.php` | General application settings |
| `auth.php` | Authentication & guards |
| `cache.php` | Cache configuration |
| `database.php` | Database connections |
| `filesystems.php` | File storage disks |
| `logging.php` | Log channels |
| `mail.php` | Mail configuration |
| `queue.php` | Queue connections |
| `services.php` | Third-party services (Google, GitHub, Stripe, etc.) |
| `session.php` | Session configuration |

---

# Accessing Configuration

Use the `config()` helper:

```php
config('app.name');
```

```php
config('database.default');
```

Setting a value at runtime:

```php
config([
    'app.timezone' => 'Asia/Kolkata'
]);
```

> Runtime changes only affect the current request.

---

# Configuration & .env

Configuration files often use the `env()` helper.

Example (`config/app.php`):

```php
'name' => env('APP_NAME', 'Laravel'),
```

This means:

- Read `APP_NAME` from `.env`
- If not found, use `"Laravel"` as the default value

---

# Configuration Cache

In production, Laravel caches all configuration files into a single file for better performance.

Cache configuration:

```bash
php artisan config:cache
```

Clear configuration cache:

```bash
php artisan config:clear
```

View cached configuration:

```bash
php artisan optimize
```

---

# Best Practices

- Access configuration using `config()`.
- Use `env()` only inside configuration files.
- Cache configuration in production.
- Store sensitive values in `.env`.
- Keep configuration organized in the appropriate config file.

---

# Common Mistakes

- Using `env()` directly in controllers or services.
- Forgetting to clear the config cache after changing `.env`.
- Hardcoding values instead of using configuration.

# Interview Questions

### 1. Where are Laravel configuration files stored?

**Answer:**  
Inside the `config/` directory.

---

### 2. How do you access a configuration value?

**Answer:**

```php
config('app.name');
```

---

### 3. Why should `config()` be preferred over `env()`?

**Answer:**  
Because `config()` works correctly with Laravel's configuration cache, while `env()` should only be used inside configuration files.

---

### 4. What command caches Laravel's configuration?

**Answer:**

```bash
php artisan config:cache
```

---

### 5. What should you do after changing the `.env` file in production?

**Answer:**  
Clear or rebuild the configuration cache.

```bash
php artisan config:clear
```

or

```bash
php artisan config:cache
```

---

# Key Takeaways

- Configuration files are stored in the `config/` directory.
- Use `config()` to access configuration values.
- Use `env()` only inside configuration files.
- Cache configuration in production for better performance.
- Clear or rebuild the configuration cache after changing `.env`.
