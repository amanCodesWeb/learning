# 1.7 API Resource Routes

## Overview

**API Resource Routes** are designed for RESTful APIs. They automatically generate CRUD routes **without** the `create` and `edit` routes, as APIs return data (usually JSON) instead of HTML forms.

Use `Route::apiResource()` when building APIs.

---

# Defining an API Resource Route

```php
use App\Http\Controllers\Api\UserController;

Route::apiResource('users', UserController::class);
```

---

# Generated Routes

| Method | URI | Action | Route Name |
|---------|-----|--------|------------|
| GET | `/users` | index | `users.index` |
| POST | `/users` | store | `users.store` |
| GET | `/users/{user}` | show | `users.show` |
| PUT/PATCH | `/users/{user}` | update | `users.update` |
| DELETE | `/users/{user}` | destroy | `users.destroy` |

View all routes:

```bash
php artisan route:list
```

---

# API Controller

Create an API resource controller:

```bash
php artisan make:controller Api/UserController --api
```

This generates a controller without the `create()` and `edit()` methods.

---

# Generated Controller Methods

```php
class UserController extends Controller
{
    public function index() {}
    public function store(Request $request) {}
    public function show(User $user) {}
    public function update(Request $request, User $user) {}
    public function destroy(User $user) {}
}
```

---

# Returning JSON Responses

API controllers typically return JSON.

```php
public function index()
{
    return response()->json(User::all());
}
```

Or simply:

```php
return User::all();
```

Laravel automatically converts Eloquent models and collections to JSON.

---

# API Resource with Middleware

```php
Route::apiResource('users', UserController::class)
    ->middleware('auth:sanctum');
```

---

# Only Specific Routes

```php
Route::apiResource('users', UserController::class)
    ->only(['index', 'show']);
```

---

# Exclude Specific Routes

```php
Route::apiResource('users', UserController::class)
    ->except(['destroy']);
```

---

# API Resources (Transformers)

Instead of returning models directly, use **API Resources** to control the JSON structure.

```bash
php artisan make:resource UserResource
```

Example:

```php
return UserResource::collection(User::all());
```

This keeps API responses consistent and secure.

---

# Best Practices

- Use `Route::apiResource()` for REST APIs.
- Return JSON responses.
- Use API Resources for response transformation.
- Protect API routes with authentication (e.g., Sanctum).
- Validate incoming requests using Form Requests.

---

# Common Mistakes

- Using `Route::resource()` for APIs.
- Returning HTML views from API controllers.
- Exposing all model attributes instead of using API Resources.
- Forgetting authentication for protected API endpoints.

---

# Interview Questions

### 1. What is `Route::apiResource()`?

**Answer:**  
It creates RESTful API routes for a controller, excluding the `create` and `edit` routes.

---

### 2. How many routes does `Route::apiResource()` generate?

**Answer:**  
It generates **5 routes**:

- index
- store
- show
- update
- destroy

---

### 3. Why are `create` and `edit` routes excluded?

**Answer:**  
Because APIs do not serve HTML forms. They exchange data, typically in JSON format.

---

### 4. How do you create an API controller?

**Answer:**

```bash
php artisan make:controller Api/UserController --api
```

---

### 5. Why should you use API Resources?

**Answer:**  
API Resources allow you to customize and standardize JSON responses while hiding sensitive or unnecessary model attributes.

---

# Resource vs API Resource

| Feature | `resource()` | `apiResource()` |
|---------|--------------|-----------------|
| Total Routes | 7 | 5 |
| `create` Route | ✅ Yes | ❌ No |
| `edit` Route | ✅ Yes | ❌ No |
| Best For | Web Applications | REST APIs |

---

# Key Takeaways

- Use `Route::apiResource()` for REST APIs.
- It generates **5 CRUD routes**.
- `create` and `edit` routes are omitted.
- Return JSON responses instead of views.
- Use API Resources to format API responses consistently.
- Protect API routes using authentication such as Laravel Sanctum.
