# 1.6 Resource Routes

## Overview

**Resource Routes** automatically generate RESTful CRUD routes for a controller using a single line of code.
Instead of defining each CRUD route manually, Laravel provides the `Route::resource()` method.

---

# Creating a Resource Controller

```bash
php artisan make:controller UserController --resource
```
This generates a controller with all CRUD methods.

---

# Defining a Resource Route

```php
use App\Http\Controllers\UserController;

Route::resource('users', UserController::class);
```

---

# Generated Routes

| Method | URI | Action | Route Name |
|---------|-----|--------|------------|
| GET | `/users` | index | `users.index` |
| GET | `/users/create` | create | `users.create` |
| POST | `/users` | store | `users.store` |
| GET | `/users/{user}` | show | `users.show` |
| GET | `/users/{user}/edit` | edit | `users.edit` |
| PUT/PATCH | `/users/{user}` | update | `users.update` |
| DELETE | `/users/{user}` | destroy | `users.destroy` |

View all routes:

```bash
php artisan route:list
```

---

# Resource Controller Methods

```php
class UserController extends Controller
{
    public function index() {}
    public function create() {}
    public function store(Request $request) {}
    public function show(User $user) {}
    public function edit(User $user) {}
    public function update(Request $request, User $user) {}
    public function destroy(User $user) {}
}
```
Laravel automatically supports **Route Model Binding** by type-hinting the model.

---

# Only Specific Routes

Generate only selected routes.

```php
Route::resource('users', UserController::class)
    ->only(['index', 'show']);
```

---

# Exclude Specific Routes

```php
Route::resource('users', UserController::class)
    ->except(['destroy']);
```

---

# Resource Route Parameters

Customize the route parameter.

```php
Route::resource('users', UserController::class)
    ->parameters([
        'users' => 'customer'
    ]);
```

Example:
/users/{customer}

---

# Resource Route Names

Customize generated route names.

```php
Route::resource('users', UserController::class)
    ->names([
        'index' => 'customers.list',
        'show'  => 'customers.view',
    ]);
```

---

# Resource Route Middleware

Apply middleware to all resource routes.

```php
Route::resource('users', UserController::class)
    ->middleware('auth');
```

---

# Resource Route with Soft Deletes

When using **Soft Deletes**, you can allow implicit model binding to retrieve soft-deleted models for selected resource routes.

```php
Route::resource('users', UserController::class)
    ->withTrashed(['show']);
```

---

# Singleton Resource

Use a singleton resource when only one instance exists (e.g., Profile, Settings).

```php
Route::singleton('profile', ProfileController::class);
```

Generated routes do not include an ID parameter.

Example:
GET    /profile
GET    /profile/edit
PUT    /profile

---

# Best Practices

- Use `Route::resource()` for CRUD operations.
- Keep controllers focused on a single resource.
- Use Route Model Binding instead of manually fetching models.
- Use `only()` or `except()` when not all CRUD actions are required.
- Follow Laravel's default route names unless customization is necessary.

---

# Common Mistakes

- Manually creating CRUD routes instead of using `Route::resource()`.
- Using inconsistent controller method names.
- Forgetting Route Model Binding.
- Creating large controllers that manage multiple resources.

# Interview Questions

### 1. What is a Resource Route?

**Answer:**  
A Resource Route automatically creates RESTful CRUD routes for a controller using a single route definition.

---

### 2. How do you create a Resource Controller?

**Answer:**

```bash
php artisan make:controller UserController --resource
```

---

### 3. How many routes does `Route::resource()` generate?

**Answer:**  
It generates **7 RESTful routes**:

- index
- create
- store
- show
- edit
- update
- destroy

---

### 4. How do you generate only specific resource routes?

**Answer:**

```php
Route::resource('users', UserController::class)
    ->only(['index', 'show']);
```

---

### 5. What is `Route::singleton()`?

**Answer:**  
It creates routes for a resource that has only one instance (such as a user profile or application settings), so no resource ID is included in the URI.

---

# Key Takeaways

- `Route::resource()` generates **7 CRUD routes**.
- Resource controllers follow RESTful conventions.
- Use `only()` and `except()` to customize generated routes.
- `Route::singleton()` is ideal for single-instance resources.
- Resource routes work seamlessly with Route Model Binding.
