# 1.14 Route Macros

## Overview

**Route Macros** allow you to add your own custom methods to Laravel's `Route` facade. They help you reuse route definitions and keep your route files clean.

Macros are useful when you repeatedly define the same type of routes across your application.

> Route macros use Laravel's **Macroable** trait.

---

# Creating a Route Macro

Macros are typically registered in a service provider.

```php
use Illuminate\Support\Facades\Route;

public function boot(): void
{
    Route::macro('adminRoutes', function () {

        Route::middleware('auth')
            ->prefix('admin')
            ->name('admin.')
            ->group(function () {

                Route::get('/dashboard', function () {
                    //
                })->name('dashboard');

            });

    });
}
```

---

# Using the Macro

Once registered, simply call it like any other Route method.

```php
Route::adminRoutes();
```

Laravel executes all routes defined inside the macro.

---

# Another Example

```php
Route::macro('healthCheck', function () {

    Route::get('/health', function () {
        return response()->json([
            'status' => 'OK'
        ]);
    });

});
```

Usage:

```php
Route::healthCheck();
```

---

# Why Use Route Macros?

Without Macro:

```php
Route::middleware('auth')
    ->prefix('admin')
    ->name('admin.')
    ->group(function () {
        //
    });

Route::middleware('auth')
    ->prefix('customer')
    ->name('customer.')
    ->group(function () {
        //
    });
```

With Macro:

```php
Route::adminRoutes();

Route::healthCheck();
```

Cleaner and reusable.

---

# Best Practices

- Register macros in a service provider.
- Use macros only for reusable route definitions.
- Give macros meaningful names.
- Keep macro logic simple.

---

# Common Mistakes

- Putting business logic inside macros.
- Creating macros for one-time use.
- Registering macros outside the application's boot process.
- Overusing macros instead of normal route groups.

---

# Interview Questions

### 1. What is a Route Macro?

**Answer:**  
A Route Macro is a custom method added to Laravel's `Route` facade, allowing reusable route definitions.

---

### 2. Where should Route Macros be registered?

**Answer:**  
Typically in a service provider's `boot()` method.

---

### 3. Which trait enables Route Macros?

**Answer:**  
The **Macroable** trait.

---

### 4. Why use Route Macros?

**Answer:**  
To reduce repetitive route definitions and improve code reusability.

---

### 5. Are Route Macros commonly used?

**Answer:**  
They are available and useful for reusable routing patterns, but they are **not commonly used in most Laravel applications**. Most projects rely on route groups, controllers, and middleware instead.

---

# Key Takeaways

- Route Macros add custom methods to the `Route` facade.
- Register them in a service provider.
- Use them for reusable routing patterns.
- Avoid putting application logic inside macros.
- Prefer Route Groups unless a reusable pattern exists.
