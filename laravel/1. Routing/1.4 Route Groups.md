# 1.4 Route Groups

## Overview

**Route Groups** allow you to apply common attributes (such as middleware, prefixes, controller, or name prefixes) to multiple routes, reducing code duplication and improving organization.

---

# Basic Route Group

```php
Route::group([], function () {

    Route::get('/users', function () {
        //
    });

    Route::get('/products', function () {
        //
    });

});
```

---

# Middleware Group

Apply the same middleware to multiple routes.

```php
Route::middleware(['auth'])->group(function () {

    Route::get('/dashboard', function () {
        //
    });

    Route::get('/profile', function () {
        //
    });

});
```

All routes inside the group require authentication.

---

# Prefix Group

Add a common URL prefix.

```php
Route::prefix('admin')->group(function () {

    Route::get('/dashboard', function () {
        //
    });

    Route::get('/users', function () {
        //
    });

});
```

Generated URLs:
/admin/dashboard
/admin/users


---

# Name Prefix Group

Add a common prefix to route names.

```php
Route::name('admin.')->group(function () {

    Route::get('/dashboard', function () {
        //
    })->name('dashboard');

    Route::get('/users', function () {
        //
    })->name('users');

});
```

Generated route names:

admin.dashboard
admin.users

---

# Controller Group

Specify a controller once for multiple routes.

```php
use App\Http\Controllers\UserController;

Route::controller(UserController::class)->group(function () {

    Route::get('/users', 'index');
    Route::get('/users/{user}', 'show');
    Route::post('/users', 'store');

});
```

---

# Combining Multiple Attributes

You can combine middleware, prefix, and name.

```php
Route::prefix('admin')
    ->name('admin.')
    ->middleware('auth')
    ->group(function () {

        Route::get('/dashboard', function () {
            //
        })->name('dashboard');

        Route::get('/users', function () {
            //
        })->name('users');

    });
```

Generated:

URL:
/admin/dashboard

Route Name:
admin.dashboard

---

# Nested Route Groups

Groups can be nested.

```php
Route::prefix('admin')->group(function () {
    Route::prefix('users')->group(function () {
        Route::get('/', function () {
            //
        });
    });
});
```

URL:
/admin/users

---

# Best Practices

- Group related routes together.
- Use middleware groups for authentication and authorization.
- Use name prefixes for better route organization.
- Use controller groups to reduce repetition.
- Avoid deeply nested route groups.

---

# Common Mistakes

- Nesting too many groups, making routes difficult to read.
- Using duplicate route names.
- Applying middleware individually when a group can be used.
- Mixing unrelated routes in the same group.

# Interview Questions

### 1. What are Route Groups?

**Answer:**  
Route Groups allow multiple routes to share common attributes like middleware, prefixes, controllers, and route name prefixes.

---

### 2. Why use Route Groups?

**Answer:**  
They reduce code duplication, improve readability, and make route management easier.

---

### 3. How do you apply middleware to multiple routes?

**Answer:**

```php
Route::middleware('auth')->group(function () {
    //
});
```

---

### 4. How do you add a URL prefix to a group?

**Answer:**

```php
Route::prefix('admin')->group(function () {
    //
});
```

---

### 5. What is a Controller Group?

**Answer:**  
A Controller Group lets you specify the controller once and define multiple routes that use methods from that controller.

```php
Route::controller(UserController::class)->group(function () {
    //
});
```

---

# Key Takeaways

- Use Route Groups to share common route attributes.
- `middleware()` → Apply middleware to multiple routes.
- `prefix()` → Add a common URL prefix.
- `name()` → Add a common route name prefix.
- `controller()` → Specify one controller for multiple routes.
- Combine multiple attributes for cleaner and more maintainable routing.
