# 1.3 Named Routes

## Overview

**Named Routes** assign a unique name to a route, allowing you to generate URLs or redirects without hardcoding the actual URI.

If the URL changes in the future, you only need to update the route definition, not every place where it's used.

---

# Defining a Named Route

Use the `name()` method.

```php
use App\Http\Controllers\UserController;

Route::get('/users', [UserController::class, 'index'])
    ->name('users.index');
```

---

# Generating URLs

Use the `route()` helper.

```php
$url = route('users.index');
```

Output:
http://localhost/users

---

# Passing Route Parameters

```php
Route::get('/users/{user}', [UserController::class, 'show'])
    ->name('users.show');
```

Generate URL:

```php
route('users.show', ['user' => 1]);
```

Output:
http://localhost/users/1

---

# Redirect Using Named Route

```php
return redirect()->route('users.index');
```

With parameters:

```php
return redirect()->route('users.show', [
    'user' => 1
]);
```

---

# Using in Blade

```blade
<a href="{{ route('users.index') }}">
    Users
</a>
```

With parameters:

```blade
<a href="{{ route('users.show', $user) }}">
    View Profile
</a>
```

Laravel automatically uses the model's route key when Route Model Binding is enabled.

---

# Naming Resource Routes

```php
Route::resource('users', UserController::class);
```

Generated names:

- users.index
- users.create
- users.store
- users.show
- users.edit
- users.update
- users.destroy

---

# Checking Current Route

```php
request()->routeIs('users.*');
```

Example:

```php
@if (request()->routeIs('users.*'))
    Active Menu
@endif
```

---

# Best Practices

- Use descriptive and consistent route names.
- Follow Laravel's resource naming convention.
- Prefer named routes over hardcoded URLs.
- Group related route names using prefixes (covered in Route Groups).

---

# Common Mistakes

- Using duplicate route names.
- Hardcoding URLs instead of using `route()`.
- Renaming routes without updating references.
- Using unclear names like `page1` or `route1`.

---

# Interview Questions

### 1. What are Named Routes?

**Answer:**  
Named Routes assign a unique name to a route, allowing URLs and redirects to be generated using the route's name instead of its URI.

---

### 2. How do you define a Named Route?

**Answer:**

```php
Route::get('/users', [UserController::class, 'index'])
    ->name('users.index');
```

---

### 3. How do you generate a URL for a Named Route?

**Answer:**

```php
route('users.index');
```

---

### 4. How do you redirect to a Named Route?

**Answer:**

```php
return redirect()->route('users.index');
```

---

### 5. Why are Named Routes preferred over hardcoded URLs?

**Answer:**  
Because if the route's URI changes, only the route definition needs updating. All `route()` references continue to work, improving maintainability.

---

# Key Takeaways

- Use `name()` to assign a name to a route.
- Use `route()` to generate URLs.
- Use `redirect()->route()` for redirects.
- Resource routes automatically generate named routes.
- Prefer named routes over hardcoded URLs for better maintainability.
