# 01. What is Laravel?

## Overview

**Laravel** is a PHP web framework used to build:

- Web applications
- REST APIs
- E-commerce systems
- Admin panels
- SaaS applications
- Backend services

Laravel provides a structured way to build applications instead of writing everything from scratch.

Laravel is a PHP framework based on the MVC architecture. It provides tools and conventions for building secure, maintainable web applications and APIs faster.
